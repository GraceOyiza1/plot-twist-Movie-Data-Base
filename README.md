# Plot-Twist-movie-data-base 🍿

This is my capstone project for the program. I wanted to build a movie site that feels like a real streaming app (like Netflix or Apple TV) rather than just a basic list of movies. I call it PlotTwist.

What I Built
The Look: I went with a dark, cinematic theme. I used a big "Hero" section at the top to grab attention and a side navigation bar that expands when you hover over it.

The Branding: I created a custom logo area called "PlotTwist" with a yellow clapperboard icon to give it a professional feel.

The Features:

Search: You can search for any movie, and it pulls real data from the OMDb API.

On-Site Theater: I built a pop-up video player. For the demo, I hardcoded high-quality trailers for The Conjuring and Inception so they play perfectly every time.

Navigation: All the links in the sidebar (Movies, Series, etc.) actually work. Since I'm still building those parts, they lead to a "Coming Soon" screen I designed.

Trending Grid: I made sure the movie titles and IMDb ratings are always visible under the posters so users don't have to guess what they're looking at.

How I Built It
React: I used React to handle the different "views" (Home, Results, Details) without the page having to refresh.

Tailwind CSS: This is how I did all the styling, like the glowing yellow borders and the smooth hover effects on the movie cards.

Lucide React: Used this for all the sharp icons in the sidebar.

OMDb API: This is the "brain" that provides all the movie titles, years, and posters when you search.
